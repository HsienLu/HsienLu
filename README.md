## ▫️ About
我是一名寫網頁的工程師。  
比起追求快或炫技，我更在意事情是否被想清楚。

我習慣從背景與限制開始，  
把模糊的想法整理成有結構、能被理解的樣子。  
寫程式對我來說，比較像是在替未來留一條清楚的路。

---

## ▫️ What I care about
- 結構是不是誠實反映需求  
- 程式碼是不是對下一個人友善  
- 使用的人會不會感到安心  

我相信，  
能長時間被使用的系統，  
通常都有一點溫柔。

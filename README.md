# Hello, welcome to my github! 👋

Hi, I'm HsienLu — a front-end engineer currently working at Zator.  
I write code, and I also spend a lot of time organizing thoughts.

Instead of rushing to build things fast,  
I prefer to slow down and make sure problems are clearly understood first.  
For me, programming is less about showing off techniques,  
and more about creating structures that are calm, readable, and easy to live with over time.
